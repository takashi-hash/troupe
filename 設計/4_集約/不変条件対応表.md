## 1. I1〜I8

| | 名前 | 守る場所 | 即時／結果 | 破れたときの見え方 |
|---|---|---|---|---|
| I1 | 抜けない | Manager の Reconciliation（Definition×Source で create） | **結果**（Reconciliation の周期ごと） | 作成されていない義務が Discrepancy として赤く出る。**見え方の出口は surface の1箇所**——判定がそこに1つしかないので、枚が増えても出しわけが割れない |
| I2 | 止まる | Job Aggregate の approve 操作 | **即時** | 担当外の approve は操作ごと失敗し、試みが Event に残る |
| I3 | 通る | Definition を enact する前の Check——Checkpoint の後ろに人手の段が残る形の Definition は enact できない | **即時**（enact 時） | その Definition は効かない（Check が止める） |
| I4 | 消えない | Space（Ledger）の構造＋Lease の期限切れで戻る仕組み | **構造** | LeaseExpired と復帰が Event に残る |
| I5 | 説明できる | AppendOnlyLog（Evidence・Event・Artifact・Utterance）＋Job からの参照 | **構造** | 参照が解決できない Evidence は Check で赤 |
| I6 | 壊れたら気づく | Check への Check——壊してみて赤くなることを確かめてから使う | **実測**（実装時） | 赤くならない Check は「有効でない」ので消す |
| I7 | 属人化しない | Briefing——参照は Ledger と Source だけを指せる。人の記憶は参照できない | **構造** | Briefing に書けない依存はその時点で露わになる |
| I8 | 動き続ける | Participant の登録＋Manager の triage・再試行 | **結果**（patrol の周期） | 起きていない Agent が MorningSheet に赤く出る |

## 2. 補強で増えた不変条件

| 名前 | 守る場所 | 即時／結果 | 破れたときの見え方 |
|---|---|---|---|
| Lease の排他（同じ Job を2体が take できない） | Job Aggregate——取り合いは版で決着 | **即時** | 負けた take は失敗、取り直し |
| Irreversible な Apply は Checkpoint 済みのみ | Job Aggregate の attempt_apply | **即時** | 操作失敗。すり抜けは事故として赤 |
| Budget を超えたら Failure | Job Aggregate | **即時** | ContentFailure へ落ち、Human に上がる |
| Briefing の無い Job は dispatch できない | dispatch の Check——参照が全部解決できるか | **即時** | dispatch されない（Check が止める） |
| 却下は再発しない | Proposal Aggregate——Fingerprint が同一性 | **即時** | 同じ Fingerprint は却下のまま。作り直せない |
| Gate（freeze 前は dispatch しない） | dispatch の Check | **ほぼ即時** | すり抜けた1件は止めず、事故として赤（CheckpointBypassed と同じ） |
| Sensitivity は届く手にだけ | Job Aggregate の take（着手）——Briefing が指す Source の SensitivityMark×Worker の CapabilityDeclaration | **即時** | take できない（操作が失敗する） |
| 適用を飛ばせない | close の門——業務ルールが「適用が要る」と言っているタスクは Confirmed から直に閉じられない | **即時** | 閉じられない（操作が失敗する） |
| 完了は証拠で閉じる | close——Evidence への参照を必ず持つ（型の材料）。読み口の無いタスクだけ SelfReport＋確かめの期限 | **構造** | 証拠なしの完了は値として作れない |
| 握りつぶさない（例外は必ず帳簿に落ちる） | 働き手と Manager の輪——捕まえて FailureOccurred を積む。逃がさない | **即時** | 履歴に残る。残っていなければ、その失敗は起きなかったことになる（I5 の系） |
| 再試行は数え切れる | triage——何度目かは帳簿の Retried の数が持つ。尽きたら ContentFailure（人へ） | **結果**（triage の周期） | 永久に繰り返さない。尽きた事実が「今日」に赤く出る |
| Irreversible は二度出ない | Apply の二相——Attempt を先に記す。試み残りの再実行は Human だけ | **即時＋構造** | Attempt 残りが ContentFailure として Human に上がる |

## 3. 読みかた

- **即時**＝1つの Aggregate の1回の書き込みが守る。破れは操作の失敗として現れる
- **結果**＝周期のある Reconciliation・patrol が守る。破れは Discrepancy・赤として現れる
- **構造**＝そもそも破れる書き方が存在しない（積むだけ・参照だけ）
- **実測**＝宣言では守れない。壊して赤を確認した Check だけが信じられる

即時で守れないものを無理に即時にしない——2つの Aggregate を1回で書く誘惑は、Boundary の間違いの合図。
