# Ichiza（一座）— 用語集

**版**: v1.0（2026-08-21）
**役目**: **業務の語と識別子の対を持つ唯一の場所。** 日本語⇄英語の橋はここだけ。

**ここに載るのは業務の語だけ。** 置き場・口・手順・判定といった**役割の語は載せない**
（前回それを載せて、「タスクの置き場」からコードの名前を作った）。
パターンの名は英語のまま扱い、[層](層.md)に住む。

---

## 1. 人と場

| 語 | 一言定義 | 識別子 |
|---|---|---|
| 人 | 判断する者。承認・差し戻し・有効化・回答は人しかできない | `Human` |
| 機体 | 仕事をこなす AI。判断はしない | `Agent` |
| 帳簿 | 起きたことと、いまの姿を持つ場。**書き換えない・消さない** | `Ledger` |

## 2. 仕事

| 語 | 一言定義 | 識別子 |
|---|---|---|
| 仕事 | 頼まれてから終わるまでの1件。一生を持つ | `Job` |
| 依頼 | 人が「これをやって」と言った事実 | `Request` |
| 期日 | その仕事を終えるべき時刻 | `DueDate` |
| 担当 | いまその仕事を持っている者。人か機体 | `Assignee` |
| 成果 | 仕事が生んだもの。出したら書き換えない | `Result` |
| 根拠 | 終わったと言える裏づけ。**人の申告ではなく、読んで確かめられるもの** | `Evidence` |
| 承認 | 人が「進んでよい」と決めた事実。誰が・いつ が必ず残る | `Approval` |
| 差し戻し | 人が「まだだ」と決めた事実。理由が必ず残る | `SendBack` |
| 質問 | 材料が足りないとき、機体が人に尋ねること。**判断は求めない** | `Question` |
| 回答 | 人が質問に答えた事実。答えは根拠になる | `Answer` |
| 使用上限 | 1件に使ってよい回数と時間 | `Budget` |

## 3. 決まり

| 語 | 一言定義 | 識別子 |
|---|---|---|
| 業務ルール | 繰り返しやる仕事の決まり。これが仕事を生む | `Rule` |
| 版 | 業務ルールの1つの姿。**積むだけ・書き換えない** | `Version` |
| 有効 | その版でいま仕事を生してよい、という人の判断 | `Active` |
| 周期 | どれくらいの間隔で仕事を生むか（月・週） | `Cycle` |
| 対象期間 | その仕事が担当する期間（2026-08、2026-W34） | `Period` |
| 受け入れ基準 | 何をもって成果とするか | `AcceptanceCriteria` |
| 検査 | 成果が受け入れ基準を満たすかを機械で見ること。**止める力を持つ** | `Check` |

## 4. 見え方

| 語 | 一言定義 | 識別子 |
|---|---|---|
| 出来事 | 起きた事実。過去形。判断を含まない | `Event` |
| 警告 | 人の目と判断が要るもの。**人が今できることが無いものは出さない** | `Alert` |
| 今日 | 今日その人が対応するものだけを集めた画面 | `Today` |
| 予定 | 先に来る仕事を見る画面 | `Schedule` |
| 履歴 | 過去に何を頼み、何が済んだかを見る画面 | `History` |
| 詳細 | 1つの仕事の「誰が・いつ・何を・どうした」 | `Detail` |
| 検索 | 終わったものも含めて、すべての仕事から引くこと | `Search` |

## 5. 操作の語（コードの動詞になる）

| 語 | 一言定義 | 識別子 |
|---|---|---|
| 頼む | 人が仕事を起こす | `request` |
| 承認する | 人が「進んでよい」と決める | `approve` |
| 差し戻す | 人が「まだだ」と決める | `send_back` |
| 答える | 人が質問に答える | `answer` |
| 有効にする | 人が版で仕事を生してよいと決める | `activate` |
| 作る | 業務ルール×対象期間 から仕事を起こす | `create` |
| 配る | 作られた仕事を着手できる状態にする | `hand_out` |
| 着手する | 担当が仕事を取る | `start` |
| 出す | 担当が成果を出す | `submit` |
| 検査する | 成果が受け入れ基準を満たすかを機械で見る | `check` |
| 時間切れを戻す | 期限の切れた担当を外し、仕事を戻す | `return_timed_out` |
| 失敗を仕分ける | 落ちた仕事を、やり直すか人へ上げるか分ける | `sort_failures` |
| 確かめる | 根拠を読んで終わりにする | `confirm` |
| 今日の分を集める | 人の目と判断が要るものを1箇所で判定する | `gather_today` |

## 6. 使わない語

| 使わない | 代わりに | なぜ |
|---|---|---|
| タスク | 仕事 | 人が「仕事」と言う |
| 定義 | 業務ルール | 「定義」は設計の語で、業務の語ではない |
| 停止点・チェックポイント | 承認待ち | 人が言う言い方に寄せる |
| 証拠 | 根拠 | 同上 |
| 置き場・口・輪・手順・仕立て | （用語集に載せない） | **役割の語であって業務の語ではない** |

---

## 7. 名前の決まり

- **識別子は英語。** 和名は用語集だけが持つ
- **1語1識別子。** 同じ語に2つの識別子を割り当てない。逆も同じ
- 型と関数の説明文に日本語の語を書く——`grep 根拠` で設計から実装へ辿れるように
- **画面に出るのは日本語の語そのまま。** 画面で言い換えない。読みにくいなら**用語集で改名する**
