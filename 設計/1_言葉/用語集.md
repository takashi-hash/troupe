## 1. この用語集は誰が読むか（未決#6前半への結論）

**人も機体も読む。** ここにあるのは**土台の言葉**——仕組みそのものの語彙。識別子としてコードに写り、画面と docstring には語のまま現れる。
各ボードの**現場の言葉**（題材ごと——運転ならリポジトリや依存、診療なら施設や担当医）はここには載せない。それは方針が持つ（歩2で決着——方針＝目的・非目標・受け入れ基準・言葉）。
この2つを混ぜないことが入れ子の要。

## 4. タスクとその一生

| 語 | 一言定義 | 識別子 |

| タスク | 一生を生きる作業の単位。指示は必ずタスクが作成される | Job |
| 作成元 | タスクがどこから作成されたかの印——業務ルールの版×対象期間／指示のメッセージ／親タスク。突合の冪等の鍵で、同じ作成元のタスクは二度作成されない | Origin |
| 発生 | タスクが作成されること。3つの道——業務ルールと源の突合・人の指示・サブタスク | Inception |
| 作成済み | 作成されたばかりで、まだ配られていない状態 | Created |

| 未着手 | 時刻・前提が揃い、機体が取れる状態（人はいつでも取れる）。解決済みの作業情報を必ず持つ | Ready |
| 期限 | タスクを終えるべき時刻。急ぎは着手可能時刻＝今・期限＝今日で表す（「緊急」という語は無い） | Deadline |
| 札 | タスクへの着手権。働き手が取り、落ちたら切れて戻る | Lease |

| 回答待ち | 尋ねて止まっている状態。答えが来たら続きから | AwaitingAnswer |
| 尋ね | 機体から人への、材料の欠けを埋める問い。判断は求めない（それは承認待ち）。答えは証拠に残る | Inquiry |
| 検証 | チェックとレビューを受けている段階 | Verification |
| 承認待ち | 人の判断待ちの地点。担当した人しか承認できない。位置は業務ルールが決める | Checkpoint |

| 完了 | 証拠で閉じた状態。人の報告に頼らない | Closed |
| エラー | 環境の失敗（自動で再試行、使用上限つき）か、中身の失敗（人へ）か | Failure |
| 成果物 | タスクが生んだもの。帳簿に置かれ、次の係が拾う。証拠が指す先 | Artifact |
| 作業情報 | タスク1件が携える文脈——読むべき源・材料・成果物の枠・受け入れ基準。作業情報の無いタスクは機体に配れない | Briefing |
| サブタスク | 実行中のタスクが生むタスク。親の受け入れ基準の内側でだけ提案なしで作成される | ChildJob |
| 進捗 | 実行中のタスクが刻む観察。「止まっている」をマネージャーが見る材料 | Progress |
| 使用上限 | 1つのタスクに使ってよい量と時間。業務ルールが決める。超えたらエラー。サブタスクの使用上限は親の残りから切り出し、連なり全体でも親を超えない | Budget |
| 芯 | タスクの全状態に共通する不変の部分——ID・作成元・時刻の対・使用上限。状態が変わっても芯は変わらない | Core |
| 状態 | タスクがいま居るところ。どれか1つ | State |
| 遷移 | 状態から状態への移り。操作が起こし、必須の出来事を必ず伴う（遷移表が正本、帳簿の書き込みが執行者） | Transition |
| 記録 | 行いを後から辿るための不変の書き付け——試みの記録・承認の記録・反映の記録 | Record |
| 試み | 外に出す前に先に記す「これからやる」の印。反映の二相の前半 | Attempt |
| 可逆 | やり直せる性質。道具に許される唯一の性質 | Reversible |

| 環境 | 失敗の種の一方——外側の事情。自動で再試行する側 | Environment |
| 中身 | 失敗の種のもう一方——成果の質。人へ上げる側 | Content |
| 自己申告 | 証拠の読み口が無いタスクの閉じ方。確かめの期限つき | SelfReport |

## 7. 設計を組み立てる言葉（境界と構成要素）

業務の語ではなく、**設計そのものを組み立てる語**。ここが空いていると、役割に名が無いまま実装が進み、置き場が毎回その場の判断で決まる（2026-08-21、実際にそうなっていた——口・輪・手順・不変条件・仕様・ポリシーがどれも中心語なのに1つも登録されていなかった）。

| 語 | 一言定義 | 識別子 |
|---|---|---|
| 境界 | 1つの言葉が一貫して通用する範囲。境界を跨ぐ言葉は必ず翻訳される | Boundary |
| 集約 | 不変条件を1回の書き込みで守る、境界の最小単位。外からは ID でだけ指す | Aggregate |
| 場 | 集約と積むだけの列の入れ物。帳簿の正体 | Space |
| 積むだけの列 | 不変の値の追記だけでできた記録。出来事・成果物・証拠・メッセージが積まれる | AppendOnlyLog |
| 種 | 判別の欄の名。どの状態・どの記録かを1語で名乗る | kind |
| 中核 | 作り込む領域。ここの出来がこの仕組みの価値そのもの。力を注ぐ | CoreDomain |
| 支援 | 要るが、それ自体は価値の源ではない領域。土台の型に中身を注げる形で薄く作る | Supporting |
| 汎用 | どこにでもある領域。買う・借りる。作らない | Generic |
| 口 | 外と話すための型。**中心が宣言し、外側が満たす**。実装を持たない——依存の向きを内へ折り返す唯一の仕掛け | Port |
| 手順 | 帳簿を開き、集約に渡し、しまうまでのひと続き。**規則を持たない**——`if` で業務を判断したくなったら、それは集約か仕様の側 | ApplicationService |
| 輪 | **周期で回る手順**。誰も呼ばなくても回る——自律の正体。全部が冪等 | Ring |
| 不変条件 | 常に真でなければならないもの。破れを**書けなくする**か、操作を失敗させる | Invariant |
| 仕様 | これは合格か、を白黒つける述語。**部品を受け取って真偽を返す** | Specification |
| ポリシー | 何をすべきかを決める規則。**データとして持ち、人が有効化する** | Policy |
| 仕立て | 新しい集約が満たすべき形。1箇所で組み立てる——**採番は立てた者、形はドメイン**。「何から決まるか」は集約境界図が持つ | Factory |
| 持ち主のない規則 | どの集約のものでもない規則。状態を持たず、部品を受け取って判定だけを返す（チェック・警告の判定・関門が開いているか） | DomainService |

## 9. 使わない語（潰した同義語）

| 使わない語 | 代わりに使う語 | 理由 |
|---|---|---|
| 仕事 | タスク | 一般的な語に揃えた（2026-08-21。前の「タスクを使わない」決定を名指しで覆す） |
| 停止点 | 承認待ち | 同上 |
| 効かせる | 有効化 | 同上 |
| 定義 | 業務ルール | 同上 |
| 憲法 | 方針 | 同上 |
| 支度 | 作業情報 | 同上 |
| 由来 | 作成元 | 同上 |
| 異常 | エラー | 同上（環境エラー／内容エラーの2種は残す） |
| 検査・点検 | チェック（機械・止める）／レビュー（AI・差し戻す） | 同上（2層の区別は残す） |
| イベント | 出来事 | 同義語 |
| 読む口 | 読み口 | 表記ゆれ |
| 書く口 | 書き口 | 同上 |

**残した近い語の区別**: 帳簿（場全体）とボード（方針を持つ区画）。出来事（観察、判断なし）と警告（人に見せる注意、判定済み）。チェック（機械・止める）とレビュー（AI・差し戻す）。
**承認と有効化は別の行為**——承認はタスクを先へ進め、有効化は業務ルール・提案を有効にする。1語にまとめない。

## 10. 画面に出る語

画面は別名を作らない（読みかた 掟10）。出してよいのは次の語だけ。**ここに無い語は「中の語」——画面に出さない**（札・芯・指紋・集約・場・積むだけの列・読み口・書き口・道具・作成元の中身の形など）。語が画面に不向きだと分かったら、画面で言い換えず、この用語集で改名する。

| 群 | 出る語 |
|---|---|
| 画面の名前 | 今日・予定・履歴・詳細・検索・チャット・ボード |
| タスクの状態 | 作成済み・未着手・実行中・回答待ち・検証中・承認待ち・承認済み・反映中・反映済み・完了・エラー |
| タスクの持ち物 | タスク・期限・成果物・作成元・作業情報・サブタスク・進捗・使用上限・証拠・担当・対象期間・状態 |
| 操作 | 承認・回答・着手・提出・有効化・再試行・キーワード・絞り込み・すべて |
| 参加者 | 人間・機体・マネージャー・働き手・受付 |
| 規則 | 業務ルール・版・提案・方針・受け入れ基準 |
| 観察 | 出来事・食い違い・警告・要対応・自己申告・メッセージ |

**この表は §2〜§8 の語の部分集合**（別名を作らないので、必ずどこかの行の語と一致する）。
状態の表示は `ui/sheets.py` の `STATE_LABELS`、画面の名前は `_PAGES` が写しを持ち、**`tests/ui_words_lint.py` が突き合わせる**（掟10 の執行者）。

迷ったら出さない側に置く。出す必要が出てきたら、そのときこの表に足す（積むだけ）。
