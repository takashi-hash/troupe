# Ichiza（一座）— 出来事

**版**: v1.0（2026-08-21）
**役目**: 起きたことを過去形で並べる。**観察だけで、判断を含まない。**

出来事は積むだけ。書き換えない・消さない。
[F4「何が起きたか説明できない」](起きてはいけないこと.md)を防ぐのはこの列。

---

## 1. 一覧（**正本**。数を数えるならここ）

| 出来事 | いつ | 何が残るか | 識別子 |
|---|---|---|---|
| 仕事が頼まれた | 人が頼んだとき | 誰が・何を頼んだか | `JobRequested` |
| 仕事が作られた | 業務ルールから、または依頼から | どの業務ルールの、どの対象期間か | `JobCreated` |
| 仕事が配られた | 着手できる状態になったとき | — | `JobHandedOut` |
| 着手された | 担当が取ったとき | 誰が取ったか | `JobStarted` |
| 手放された | 担当が離したとき | 誰が離したか | `JobReleased` |
| 時間切れで戻った | 担当が期限までに終えなかったとき | 誰の担当だったか | `JobTimedOut` |
| 成果が出された | 担当が出したとき | 成果の在りか | `ResultSubmitted` |
| 検査に通った | 検査が通したとき | — | `CheckPassed` |
| 検査で止まった | 検査が止めたとき | 止めた理由 | `CheckStopped` |
| 承認された | **人**が承認したとき | 誰が・いつ | `Approved` |
| 差し戻された | **人**が差し戻したとき | 誰が・理由 | `SentBack` |
| 終わった | 根拠が揃ったとき | 根拠の在りか | `JobFinished` |
| 期日を過ぎた | 期日を越えたとき | — | `DueDatePassed` |
| 失敗した | 途中で落ちたとき | 何が起きたか | `JobFailed` |

---

## 2. 書きかたの決まり

- **全部過去形。** 「承認する」ではなく「承認された」
- **判断を含まない。** 「不正な承認がされた」は書けない——不正かどうかは判断。
  書けるのは「承認された」まで
- **人が主語のものに印を付ける**（上の表の太字）。承認・差し戻し・有効化・回答。
  ここが**判断は人間**の実物

## 3. どの失敗に効くか

| 出来事 | 効く失敗 |
|---|---|
| 承認された・差し戻された | F3（判断していないのに外に出る） |
| 全部 | F4（説明できない） |
| 終わった（根拠の在りかつき） | F5（終わったことになっている） |
| 期日を過ぎた | F1（気づかれず期日を過ぎる） |
| 仕事が作られた | F2（思い出さないと始まらない） |
