# Ichiza（一座）— 人に見えるもの

**版**: v2.0（2026-08-22）
**役目**: 画面と、画面へ渡す値。**業務の判断を1つもしない。**

---

## 1. 画面

| 画面 | 答える問い | 出すもの | どの失敗のためか |
|---|---|---|---|
| **今日** | いま私の判断と目が要るものは？ | `judge_today` が返したものだけ | F1・F6 |
| **予定** | 先に何が来る？ | 作られた仕事（**終点以外の列——検索の行で出し、行から詳細が開く**）と、業務ルール×暦から導く未作成のもの | F1 |
| **履歴** | 過去に何を頼み、何が済んだ？ | 出来事の列（**どの仕事かの見出しつき**——行から詳細が開く） | F4 |
| **詳細** | この仕事は誰が・いつ・何を・どうした？ | 出来事の全部と、質問・回答・見立ての本文 | F4 |
| **検索** | あの仕事はどこ？ | 終わったものも含めて引く | F1 |
| **患者** | この人は誰で、何が起きている？ | 診療録（**よそのコンテキスト**）の写し。承認の前にカルテを見るための参照——**中の語に翻訳しない・帳簿に書かない** | F4 |
| **道順** | 今日、誰がどの順で回る？ | その日の担当ごとの訪問を拠点から近い順に。地図と距離——**患者宅の代役は公共の場所**（実在の自宅を1つも指さない） | F1 |
| **定期訪問** | 誰と何を取り決めている？ | 取り決めの一覧と、載せる・終える——**取り決めこそが人の判断**。展開は脈がやる | F1 |
| **当日入力** | いまこの訪問で何を記録する？ | 道順の停留から開く。**下書きが初期値**の S/O/A/P と署名——署名で訪問は実施済み・下書きは使用済みになり、**記録は翌週の AI の材料になる** | F4 |
| **案内** | いま何をどこですればいい？ | 問いへの答えの文字と、**画面への白名単リンクだけ**（外への誘いは文字のまま）。答えを組むのは LLM——**押すのは人**。帳簿に書かない | F6 |
| **説明** | この仕組みは何がどう動く？ | 環の図・登場人物・色の語彙・**AI にできないこと**。静的——**集める操作は無い** | F6 |

**押しつけは「今日」だけ。** 残りは引き出し。この分け方が F6（読まれなくなる）を防ぐ。

## 2. 画面へ渡す値

**画面に届くのは文字と ID だけ。** 集約も値オブジェクトも出さない。
**今日の材料**（仕様が見る domain の値）と**今日の行**（画面が見る文字）は別物——`gather_today` が 材料 → 仕様 → 行 の順に詰め替える。
**詰め替えるのは app**——画面が自分で詰め替えると、画面が中心の形を知ることになる。

| 値 | 中身 |
|---|---|
| 今日の行（**正本**） | 仕事の識別子・`RuleName` と生まれた版の番号・**対象期間**（依頼発は依頼の中身の先頭）・**やること**（生まれたとき写したもの——**元の内容が無いと承認しようがない**）・状態の名・期日・担当の名・確かめ期日・**成果の中身**・**根拠の引用**・**質問の本文**・**回答の本文**・**見立ての本文と理由**・**やり直しが尽きたか**・**使った量と上限**・受け持ちの人・**押せること** |
　　　　└ 本文をそのまま載せる。**押しつけの画面でだけ縮めない**。**受け持ちの人は見る人と同じ**（§3）なので画面には出さない |
| 出来事の行 | 時刻・**誰が**（名、無ければ**起こす者の語**——橋は1つ）・何が起きたか |
| 予定の行 | 業務ルールの名・やること・版の番号・有効な版・次の対象期間・押せること |
| 詳細 | 仕事の識別子・**やること**・状態の名・期日・担当・**成果の中身**・根拠の引用・確かめ期日・**問答の対の全列**（今日は最新の1対だけ、詳細は全部）・**見立ての本文と理由**・押せること・出来事の列 |
| 履歴の行 | 時刻・誰が・何が起きたか・**仕事の識別子・見出し**（業務ルールと対象期間、無ければやることの先頭） |
| 検索の行 | 仕事の識別子・見出し・対象期間・やること・状態の名・期日・担当の名 |
| 絞り込みの条件 | キーワード・状態の表示・業務ルール・担当（**文字だけ**） |
| 患者の行 | 患者記号・年齢・生活状況・主病名・次の訪問・指示書の期限（**よその語のまま**） |
| 道順の行 | 順番・**訪問の識別子**・患者記号・場所の名（公共の代役）・予定の目的・**前の地点からの距離**・座標（地図を描くためだけ）・**下書きの支度**（署名済み／下書きあり／無し）・**状態**（予定／実施済み／中止——**済んだ訪問も今日の並びに残る**。進捗が見えない道順は現場で使えない） |
| 取り決めの行 | 識別子・患者記号・曜日・**週の間隔**・担当・目的・始まり・終わり |
| 訪問の詳細 | 訪問の識別子・日付・患者の要約（患者の行の全欄）・**未使用の下書き**（本文と識別子）・**署名済みの記録の列**・担当の名簿。**押せるのは署名と1回だけ休むの2つ** |
| 患者の詳細 | 患者の行の全欄＋**いま継続中の処方**の列・状態変化の列・**下書き（Troupe が置いた提案。署名前）**の列・**署名済みの記録**の列（日付・担当・S・O・A・P）。**押せることは無い**——読むだけの写し。**下書きと署名済みは別の欄**——提案と事実を1つの列に混ぜない |

| 案内の答え | 問いの文字・答えの文字・直近の往復（**画面が持ち回る——帳簿に置かない**） |

**振る舞いを持たない。** ただの入れ物。

### 質問・回答・見立ては、そのまま届く——この仕組みの値打ちが、ここで人に渡る

| 欄 | 執行者 | 壊しかた |
|---|---|---|
| 質問の本文 | `gather_today` の詰め替え（そのまま載せる）＋週Aの通し | 要約や切り詰めが入ったら赤 |
| 回答の本文 | 同上 | 同上 |
| 見立ての本文とそう読んだ理由 | 同上＋`Assessment` の義務（理由が空で作れない） | 理由の空な見立てが画面に出たら赤 |

**縮めない**——縮めると判断の材料が減る。見立てが無いと、座長に届くのは「20回使い切りました」という数字だけになる。

## 3. 押せること

**組むのは domain の仕様**（「いまこの仕事に人が押せる操作はどれか」）。
app が尋ね、返ってきたものを値に入れる。**画面は入っているものを出すだけ。**

| 操作 | 出る画面 | 誰に出るか |
|---|---|---|
| 承認する | 今日・詳細 | **受け持ちの人にだけ** |
| 差し戻す | 今日・詳細 | 受け持ちの人にだけ |
| 答える | 今日・詳細 | 尋ねられた人（＝受け持ちの人）にだけ |
| 打ち切る | 今日・詳細 | 受け持ちの人にだけ |
| **版を積む**・**有効にする**・**止める** | 予定 | 人なら誰でも（版の欄は**題材のデータが初期値、人が上書き**）。**止めるは有効な版があるときだけ**——組むのは仕様。**今日には出ない** |
| **定期訪問を決める**・**終える** | 定期訪問 | 人なら誰でも（患者と調整済みの取り決めを載せる/終える）。**終えると由来の未来の予定は中止に倒れる** |
| **署名して訪問を終える**・**訪問を1回だけ休む** | 当日入力 | 人なら誰でも（署名者は名簿から名指す。初期値は担当）。**署名は予定のままの訪問にだけ**——実施済み・中止済みには断り |
| **頼む** | 予定 | 人なら誰でも（一度きりの仕事）。**人が必ず書くのは 頼む中身・源・必ず含む語だけ**——残りは既定（正本は[筋道 §1](仕事が回る筋道.md)）。頼んだ直後から**予定の仕事の列に見え**、判断が要るときだけ今日に出る |

**押して何も起きないのが一番わるい。** 断られたら**断り**（`Refusal`）として理由を出す
（担当ではない・もう誰かが承認した）。**操作の失敗はエラーではない**——
仕事の状態は変わらないので、一生に傷をつけず、画面にだけ理由を出す。

## 4. 今日に何を出すか

**判定するのは `judge_today`。ここは並べるだけ。**

| 出すもの | 人がいま押せること |
|---|---|
| 承認を待っている | 承認する・差し戻す |
| 答えを待っている | 答える |
| **見立てが書かれた**（実行中・失敗した に限る） | 差し戻す・打ち切る（**読むだけでは押せることにならない**） |
| 期日を過ぎていて、人が押せる操作がある | その操作 |
| 確かめ期日が来た自己申告 | 差し戻す |
| やり直しが尽きて残っている | 差し戻す・打ち切る |

**各行が「人がいま押せること」を1つ以上持つ。** 持たない行は出さない。

### 出さないもの

| 出さないもの | なぜ |
|---|---|
| AI が実行中で、**見立ての書かれていない**仕事 | 人がいまできることが無い（見立てが在れば出る） |
| 自動でやり直している最中の失敗 | 同上 |
| 期日前で、人がいま押せる操作が**無い**仕事 | 先の予定は今日に載せない（赤が埋もれる）。**押せる操作があれば期日前でも出る** |
| 終わった仕事・打ち切った仕事 | 済んでいる |

**同じものが毎日出続けたら設計の失敗**（F6）——押せる操作が本当にあるかを疑う。

## 5. 決まり

- **画面に出るのは用語集の語そのまま。** 画面で言い換えない。
  読みにくいと分かったら**用語集で改名する**。
  日本語を読まない人に見せるときは**用語集の識別子を併記してよい**——
  訳を作るのではなく[用語集](仕事とは何か.md)の橋をそのまま出す。**橋は `words` の1枚のまま**
- **一覧の読みは集約を再構成しない。** Reader が画面に要る形で引く。
  **守るべき境界が無い読みに、集約の形は要らない**
- **画面は domain を import しない**
