# Ichiza（一座）— 執行者

**版**: v1.0（2026-08-21）
**役目**: **誰が何を赤くするかの正本。** ここに無い執行者は無い。

前回の執行者は7つあって、**全部が「名前と住むところ」の見張り**だった——依存の向き・
語の対訳・画面の語・出来事の名前・フォルダの名前・アプリケーションサービスの一覧・置き場。
「**型が正しさを保証しているか**」の執行者は1つも無かった。

だから名前は揃い、住むところも揃い、依存の向きも守られ、**中身だけが空だった。**

---

## 1. 執行者の種類

**種類が偏ったら未完成。** 名前と住むところだけになっていないか、この欄で数える。

| 種類 | 何を守るか |
|---|---|
| **型** | 不正な値・不正な状態が**書けない** |
| **検査** | 例が仕様。この材料ならこうなる、を1行1つ |
| **突合** | 設計の表と実物が一致しているか |
| **人** | 誰がいつ読むかまで書けるものだけ |

## 2. 一覧（**正本**）

| 執行者 | 何を守るか | 種類 | 壊して赤を見た日 |
|---|---|---|---|
| 値の義務 | [値オブジェクトとエンティティ](値オブジェクトとエンティティ.md)の義務の欄が全部効いているか。**義務の書かれた値が検証を持っているか** | 型＋検査 | まだ |
| 禁止値 | [型で殺す](型で殺す.md)の値の行が全部書けないか | 型 | まだ |
| 禁止状態 | 同・状態の行 | 型 | まだ |
| 不変条件 | [集約と不変条件](集約と不変条件.md)の各行。即時のものは操作で、結果のものは周期で | 型＋検査 | まだ |
| 書き込みの門 | I1・I2——**姿の変化と理由の出来事が一緒でなければ書けない** | 型 | まだ |
| 集約の数 | [集約](集約と不変条件.md)の各行が、要求した不変条件を指しているか | 突合 | まだ |
| アプリケーションサービスの一覧 | [アプリケーションサービス](アプリケーションサービス.md)の表と実物が一致しているか | 突合 | まだ |

| この表自身 | 執行者の欄が空の行が無いか。**種類が偏っていないか** | 突合 | まだ |

## 3. 決まり

- **「壊して赤を見た日」が空の執行者は、置いたと言わない**
- **儀式そのものが嘘をつくことがある。** 前回、終了コードをパイプで隠していて
  「緑のまま」と誤って読んだ。**赤の中身まで見る**
- **執行者を消すときは、守っていたものを先に消す。** 順が逆だと、守るものだけが残る
- この表に載らない執行者を作らない。載らないものは、次に誰かが消したとき誰も気づかない

## 4. いま

**全部「まだ」。** 設計を書き終えた時点で、執行者は1つも置いていない。
実装を始めるとき、**上から順に置く**——値の義務・禁止値・禁止状態が先。
前回はここを最後まで置かなかった。
